# Trip Planner

A kid-friendly trip-planning web app.

## What it does
- Choose a destination city
- Search nearby attractions, restaurants, museums, and other places
- Add destinations to the trip
- Optimize the driving order using OSRM
- Open the completed route in Google Maps
- Save contact information, official website or ticket links, and ticket prices
- Save the trip locally on the device
- Install as a web app from GitHub Pages

## Publish with GitHub Pages
1. Make the repository public if needed.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save.

The site address will be:
`https://pabitzkyt-sys.github.io/Trip_planner/`

## Data services
Destination search uses OpenStreetMap Nominatim. Route optimization uses the public OSRM routing service. Contact information and ticket prices vary by destination and are saved manually in each stop's Details screen.
